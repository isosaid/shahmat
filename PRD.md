# PRD — Shahmatnameh (Санъати шоҳмот)

Шахматный сайт с таджикским колоритом: игра, задачи, партии чемпионов, библиотека книг, советы.
Один автономный HTML-файл (`index.html`), работает офлайн, без сервера и без внешних зависимостей.

---

## 1. Принятые решения

| Область | Решение |
|---|---|
| Бренд | Название `SHAHMATNAMEH`, подзаголовок `САНЪАТИ ШОҲМОТ`, приветствие `Хуш омадед ба` — латиницей/кириллицей как на постере, без перевода |
| Шапка | Фото-постер пользователя как баннер, встроен в файл (base64) |
| Орнамент | Декоративная полоса под шапкой **удалена** |
| Доска | Классическая стандартная: клетки `#f0d9b5` / `#b58863`, без текстур и золотых рамок |
| Фигуры | Стандартные чёрные и белые (Unicode-символы), без кастомной SVG-графики |
| Координаты | Стандартные, **с четырёх сторон**: цифры 1–8 слева и справа, буквы a–h сверху и снизу; переворачиваются вместе с доской |
| Разделы | Бози (игра), Масъалаҳо (задачи), Партияҳо (партии), Китобхона (книги), Маслиҳатҳо (советы) |
| Зависимости | Внешний CDN **не используется** — chess.js встроен в файл |

## 2. Функции

### Бози — игра
- Полные правила: рокировка, взятие на проходе, превращение пешки, шах, мат, пат, ничья
- Режимы: на одном устройстве / против компьютера / онлайн по коду комнаты (асинхронно)
- Переворот доски, отмена хода, список ходов, взятые фигуры

### Часы
- Контроли: Без часов, Пуля 1+0, Блиц 3+2, Блиц 5+0, Рапид 10+0, Рапид 15+10, Классика 30+0
- Инкремент начисляется после хода; под 20 с показываются десятые доли; под 30 с время краснеет
- Пауза/Продолжить; при падении флага партия останавливается и объявляется результат
- Компьютер расходует своё время наравне с игроком

### Соперник — чемпионы мира ФИДЕ
Выбор из 18 чемпионов по порядку: Стейниц → Ласкер → Капабланка → Алехин → Эйве → Ботвинник → Смыслов → Таль → Петросян → Спасский → Фишер → Карпов → Каспаров → Крамник → Ананд → Карлсен → Дин Лижэнь → Гукеш Доммараджу (действующий, с 2024).

Каждый привязан к одному из 5 профилей движка (глубина расчёта + веса оценки позиции) по репутации стиля. **Это не копии реальной игры чемпионов и не воспроизведение их партий** — так и указано в интерфейсе.

### Масъалаҳо — задачи
5 тактических задач с проверкой решения на мини-доске (вилка, мат в 1, скьюер, двойной удар). Все позиции проверены на легальность через python-chess.

### Партияҳо — партии
7 исторических партий с пошаговым просмотром.

### Китобхона — книги
16 книг со ссылками на легальные бесплатные источники: 11 — Project Gutenberg (свободно скачать), 5 — Internet Archive (чтение онлайн). Поиск и фильтр по типу доступа. Тексты книг не размещаются; книги под авторским правом не включаются.

### Маслиҳатҳо — советы
8 принципов игры, 10 дебютов, глоссарий на 12 терминов.

## 2a. Образовательная платформа (Омӯзиш)

Реализовано без сервера, полностью на клиенте:

- **Каталог курсов** — 5 уровней (начальный → турнирная подготовка), фильтр по уровню, полоса прогресса на каждой карточке
- **Курсы** — 21 урок в 5 курсах; начальный курс покрывает программу из ТЗ п. 7.2 (доска, фигуры, ходы, шах, мат, пат, рокировка, превращение, дебют, тактика, эндшпиль)
- **Урок** — теория, иллюстрирующая позиция на доске, интерактивная задача с проверкой хода и подсказкой, тест
- **Тесты** — вопросы с одним правильным ответом, проходной балл 70%, подсветка верных и ошибочных ответов
- **Условие завершения** — урок нельзя отметить пройденным, пока не решены задача и тест (требование ТЗ п. 8)
- **Прогресс** — сохраняется автоматически, переживает перезагрузку страницы
- **Баллы** — 20 за урок, 15 за тест, 10 за задачу
- **Достижения** — 7 наград (первый урок, 5 и 10 уроков, тактик, знаток теории, курс завершён, 100 баллов)
- **Сертификат** — выдаётся после 100% курса, с именем, курсом, уровнем, датой и уникальным номером; печать или сохранение в PDF через диалог печати браузера
- **Личный кабинет** — статистика, прогресс по каждому курсу, достижения, сброс прогресса
- **Языки** — русский, таджикский и английский: переключаются интерфейс, названия курсов, тексты уроков и вопросы тестов
- **Темы** — светлая и тёмная, выбор запоминается

### Хранилище

Слой `Store` использует `window.storage`, если он доступен, иначе `localStorage`. Это позволяет одному файлу работать и в среде Claude, и на GitHub Pages.

## 2b. Чего нет и почему

Эти пункты ТЗ требуют серверной части (backend, база данных, почтовый сервис) и не могут быть выполнены в статическом файле:

| Пункт ТЗ | Причина |
|---|---|
| Регистрация, вход, восстановление пароля | Нужны сервер, БД и почтовая рассылка. Имитация входа создала бы ложное чувство защищённости |
| Вход через Google / Telegram | Требуется OAuth-сервер и секретные ключи |
| Роли: тренер, администратор | Проверка прав возможна только на сервере |
| Админ-панель, управление пользователями | То же |
| Общая аналитика по всем ученикам | Нужна общая база данных |
| Уведомления по почте и в Telegram | Нужен сервер рассылки |
| Проверка открытых ответов тренером | Нужен аккаунт тренера и хранилище ответов |
| Видеоуроки | Нужен хостинг видео; в вёрстке уроков место под видео предусмотрено |

Прогресс сейчас привязан к браузеру, а не к аккаунту: при смене устройства он не переносится.

**Следующий шаг для полной реализации ТЗ** — backend (например, Supabase или Firebase: они дают аутентификацию, БД и хранилище файлов без написания серверного кода) либо классическая связка PHP/Node + PostgreSQL.

## 2c. Дополнения второй итерации

- **Главная страница** — описание платформы, преимущества, статистика, уровни, популярные курсы, свежие материалы, кнопки «Начать обучение» и «Играть»
- **Новости и статьи** — 5 публикаций с категорией, автором, датой и счётчиком просмотров, чтение в модальном окне
- **Поиск** — по курсам, урокам, задачам, статьям, книгам и партиям; переход прямо к найденному
- **Уведомления** — внутри сайта: новые достижения, незавершённые курсы, доступные сертификаты; индикатор непрочитанного
- **Расширенный профиль** — имя, фамилия, город, страна, уровень, о себе + шахматные данные: FIDE ID, рейтинг, разряд, клуб, тренер, предпочитаемый контроль времени
- **История активности** и учёт посещений (достижение «Неделя без пропусков»)
- **Информационные страницы** — «О проекте», пользовательское соглашение, политика конфиденциальности
- **Сертификат дополнен** — итоговый результат по тестам, подпись и код проверки
- **Английский язык** — третий язык интерфейса; переведены интерфейс, уровни, названия и описания курсов, заголовки и теория всех 21 урока, вопросы и варианты ответов тестов, достижения, новости

## 2d. Аккаунты и админ-панель — демонстрационные

Реализованы как макет интерфейса:

- **Регистрация** с валидацией по ТЗ п. 5.1: имя, фамилия, почта, телефон, уровень подготовки, пароль с подтверждением, два обязательных согласия
- **Вход и выход**, прогресс привязывается к аккаунту и изолирован между пользователями
- **Роли**: ученик, тренер, администратор
- **Админ-панель**: список пользователей с поиском, просмотр прогресса, смена роли, блокировка и удаление; аналитика (всего пользователей, активных за 7 дней, заблокированных, выданных сертификатов, средний результат тестов, популярные курсы); список курсов с автором, длительностью и статусом
- Заблокированный пользователь не может войти; вкладка админки скрыта от обычных учеников

**Это не система безопасности.** Весь код выполняется в браузере, поэтому любой человек может открыть исходник, прочитать учётные данные администратора и обойти проверку прав. Пароли хранятся не в открытом виде, но использованная контрольная сумма не является криптографической защитой. Данные видны только в том браузере, где созданы, и не синхронизируются между устройствами.

Учётные данные администратора по умолчанию: `admin@shahmatnameh.tj` / `admin12345`.

**Для работы с реальными клиентами обязателен backend.** Минимально необходимое: серверная аутентификация с хешированием паролей (bcrypt/argon2), проверка ролей на сервере, общая база данных, подтверждение почты. Быстрее всего это закрывается через Supabase или Firebase.

## 3. Движок

Minimax с альфа-бета отсечением, сортировка ходов (взятия первыми), адаптивная глубина (2 при >34 ходах, иначе 3), выбор среди равноценных ходов для разнообразия стилей.

**Результаты оптимизации:**

| Позиция | До | После | Ускорение |
|---|---|---|---|
| Миттельшпиль | 3777 мс | 492 мс | 7,7× |
| Сложная | 7190 мс | 496 мс | 14,5× |

Тесты на зевки (12 попыток каждый): бесплатный ферзь 12/12, бесплатная ладья 12/12, мат в 1 — 12/12.

## 4. Известные ограничения

- Онлайн-режим асинхронный (опрос раз в 4 с), не реальное время — для мгновенных ходов нужен WebSocket-сервер
- Движок любительского уровня, не соперник настоящим шахматным программам
- Шрифты подгружаются с Google Fonts; без сети откатываются на системные (на работу сайта не влияет)
